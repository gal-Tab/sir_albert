Header

GoalOne repo is the live install: no symlink, no second marketplace, no local-vs-GitHub drift. Architecturegit subtree add brings the KB in with its history under plugins/kb. sir-albert moves with git mv into plugins/sir-albert and keeps its name, so sir-albert:* references are unchanged. KB is renamed llm-wiki-agent → kb. Repo data (raw/, wiki/) stays at the root. Stackgit (subtree), Claude Code plugin marketplace (local directory), pytest, launchd, /sir-albert:create-skill for every SKILL.md edit EffortM: about half a day for the builder, plus 4 approval checkpoints BuilderSonnet 5 subagent; the coordinator (main session) answers questions and holds the checkpoints Not includedSkill consolidation, router hooks, CLAUDE.md rewrite (W2–W3), dapulse migration, archiving the GitHub repo

Definition of Done

  • A fresh session lists sir-albert:* and kb:* skills and no llm-wiki-agent:*
  • KB pytest suite passes from plugins/kb
  • Every hook (guard, freeze, validate-skill, session-record, kb status/learn) and both launchd jobs run from the new paths
  • The stale-name grep (llm-wiki-agent | kb-query | kb-compile) is empty across the repo and ~/.claude
  • The edit loop is known and tested: an edit in the repo shows up in a new session
