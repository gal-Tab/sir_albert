## Selection Guide

| Idea Type | Recommended Voices |
|-----------|-------------------|
| Product / feature | YC, Shreyas, Karpathy |
| Technical architecture | Boris, Karpathy |
| Go-to-market / distribution | Verna, YC, Collison |
| Growth / metrics claim | Kohavi, Verna |
| Strategy / vision | Collison, Karpathy, YC |
| Workflow / process design | Boris, Shreyas |
| Ambiguous / early-stage | YC, Karpathy, Boris |
| Stalled / overthought (discussed longer than tested) | Seibel, YC |

Default: pick the 2–3 voices with the highest overlap to the idea type. Always include at
least one "market" voice (YC, Verna, or Shreyas) and one "craft" voice (Boris or Karpathy).
